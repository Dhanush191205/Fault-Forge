## Access and extraction notes

- Parker P1/PD and vane-pump PDFs returned HTTP 403 to the local downloader. Their web content was reviewed; no local PDF is claimed.
- Rexroth diagnostic pages 49–51 were visually reviewed. They are image content and require OCR plus table checking before bulk retrieval ingestion.
- The Rexroth host filename mentions 2025; the cover and embedded RE 07009-B/09.09 edition are older. File upload dates are not manual revisions.
- Haas spindle guidance includes a displayed inch/mm runout inconsistency in the retrieved page. No numerical limit from that line is imported into these drafts.
- CITS is an instructor-training curriculum. It is supplementary assessment design evidence, not a trainee qualification or a project certification.
- Public accessibility does not establish permission to redistribute a manual, send it to external inference, or fine-tune a model. Those flags remain false pending an established basis.
