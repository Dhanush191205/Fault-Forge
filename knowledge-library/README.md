# Reference library

This folder catalogs candidate references for the CNC, hydraulic press and conveyor curriculum. Sources require equipment, rights and instructor review before use in scenario generation.

- [Source catalog](SOURCE-CATALOG.md)
- [Machine-readable source register](source-register.json)
- `scripts/`: original collection, preparation and auditing tools

The GitHub repository includes the catalog, register and scripts. Downloaded third-party documents, extracted content and the separate reference-report application remain local. Local-material links in the catalog resolve only when those documents have been collected; use each entry's official source link online.

The working simulator uses the original synthetic fixtures in `application/data/`, independently of this reference collection.
